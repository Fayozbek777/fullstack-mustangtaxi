## ✨ Что это

Веб-платформа **Mustang** — аренда электросамокатов, велосипедов и
термосумок для курьеров в Ташкенте. Сайт с адаптивным дизайном,
плавными анимациями и формой заявки.

---

## 🎯 Возможности

| Раздел | Описание |
|--------|----------|
| 🏠 **Bosh Sahifa** | Hero с фоновым видео, секции о нас, тарифы, контакты |
| 🛴 **Skuterlar** | Каталог электросамокатов с фильтрами и формой заявки |
| 🚴 **Velosipedlar** | Каталог велосипедов |
| 🛍️ **Sumkalar** | Термосумки для Yandex Delivery, Wolt |
| 📩 **Заявка** | Форма с валидацией, маской телефона, AJAX-submit |
| 📄 **Shartnoma** | Скачивание договора в DOCX + видеоинструкция |
| 🌐 **Языки** | UZ / RU / EN / HI / UR |
| 🗺️ **Карта** | Google Maps с адресом офиса |

---

## 🛠 Стек

- **Backend:** Django 6.1, SQLite
- **Frontend:** HTML5  Tailwind CSS , Motion One, Font Awesome 6
- **Admin:** Jazzmin
- **Шрифт:** Inter
